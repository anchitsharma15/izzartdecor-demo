# IzzartDecor demo

Live site: https://izzartdecor.com/

Custom domain: izzartdecor.com, with www redirecting to the root domain. DNS is managed in Hostinger; hosting is provided by GitHub Pages.

Compact anniversary page for Di and Jiju. Five-photo carousel with crossfades, swipe and keyboard navigation, pause control, animated hearts and an original synthesized background music loop.

All five photographs are still frames selected from the same Instagram reel, captioned “life line”: https://www.instagram.com/reel/Dfr8F6vRO0v/

The page attempts audio playback on opening. Browsers may require a tap first; the sound button always provides play/mute control. The music is an original instrumental loop created with Web Audio, not the reel's soundtrack.

No build step. Serve index.html and memory-1.jpg through memory-5.jpg together. GitHub Pages source: main, /(root). This is the development demo repository for later IzzartDecor work.
